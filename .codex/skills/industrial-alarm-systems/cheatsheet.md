## 条件与选择

| 如果看到或已知 | 书中对应判断 |
|---|---|
| 正常/异常分布可估，IID 假设合理 | 用§2.1的概率与 Markov 链设计；不能只凭低自相关认定 IID |
| 缺少状态分布，但有均值差异及工艺先验 | 查§2.1.3分段、段均值检验、KDE；不确定段不参与估计 |
| 想从历史判断延时能过滤哪些短越限、短回落 | 查§2.2；统计连续段长度，IID、非 IID 都可用 |
| 干扰短促越限 | 优先看延时机制 |
| 干扰越限幅度小、持续较长 | 看 Deadband Index，适用性显著后再设计宽度 |
| 想提前提醒，又少报会自行回落的波动 | 查§2.4；比较走向原阈值的可能性和可争取的提前量 |
| 每支变量都在固定范围，联合组合却不合理 | 查§3.1 NOZ 或§3.2方向关系 |
| 正常区明显非凸 | 凸包可能填平凹陷，考虑 search cones |
| 已有泵或冷凝器机理及对应测量 | 查设备专用法，保留物理量、单位与模型假设 |
| 报警先后顺序不稳定 | 看随机延迟及显著信息流，不只看谁先发生 |
| 当前报警有已知二值候选原因集合 | 查§4.3组合后验，注意独立原因及结构条件 |
| 原因随时段改变 | 查§4.4趋势分段、时延和贡献 |
| 一个 Tag 抖动导致很多发生次数 | 洪泛计数要区别发生次数与参与变量数 |
| 想比较次序 | 用序列对齐；共现模式则用事务集合 |
| 想找负担集中时段与 Tag | 用 HDAP 看每格发生次数，持续状态另查 |
| 想比较操作员响应是否更快 | 分清发生→确认、发生→动作、动作→解除的间隔，并固定对齐点 |

## 几个数值如何读

- **n** 是采样点数；物理延时还需采样周期。书中§2.1延时器对激活和解除都延时。
- **45°** 是§2.3死区适用性参考，还需显著性判断。
- **5%** 在§2.3是剩余干扰事件比例的默认示例，不是正常期报警时长比例。
- **β** 在§3.1控制正常建模数据的排除比例；解释为后续 FAR 有分布一致等前提。
- **10分钟/10个、长期30分钟、预处理20秒** 属于§5.1对应判据与流程；换采样率需保持物理时间含义。

## 快速识别误读

- 把 x、xa 和发生日志混称为同一种输入 → 回 ch01 的对象定义。
- 看到 FAR/MAR 就直接与任意分类分数比较 → 核对 ch02 各节的分母和统计对象。
- 看到变点就判故障 → 还缺过程状态解释；不同正常工况也会变。
- 看到 deadband 参数一样就比较 → 核对激活、解除两条边界。
- 看到关联图就称当前根因已找到 → 区分关系发现与事件诊断。
- 把代表模式关联 TID 当成并集模式支持度 → 回查原始事务，区分概括与实际共同出现。
- 看到图中长横带就说一直未解除 → 先读图例，是发生次数还是报警状态。
- 看到很少报警就说优化成功 → 同时核对漏报、及时性及处置意义。
- 用笔记重建精确公式有疑问 → 回所标 PDF 页，保留未核实项。
